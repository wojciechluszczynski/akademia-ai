## Skill Library (Claude Code / Cowork)

Gotowe skille to najszybszy sposób na zasilenie Workflow/SOP Library. Zamiast budować od zera:

1. Szukaj na [Skillta.com](https://skillta.com/) po use case (np. "content audit", "cold email review")
2. Przetestuj na 3 realnych przypadkach zanim wpiszesz do backloga
3. Wpisz do **AI Use Case Backlog** ze statusem `test` → po walidacji zmień na `live`
4. Jeśli budujesz własny skill — udostępnij go na Skillta (wzmacnia brand eksperta)

→ Szczegółowy przewodnik: Vault · **Skillta — Katalog Skilli dla Claude Code**

## Governance rule

Jeśli AI output może trafić do klienta, kampanii, CRM, strony, oferty lub publicznej komunikacji, musi mieć właściciela i quality gate.
